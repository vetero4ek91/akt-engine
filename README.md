# akt-engine

Движки форм актов осмотра ТС и имущества (docx → PDF). Только пустые формы:
данные акта, ФИО эксперта и подпись передаются снаружи и здесь не хранятся.

- `favorit_engine.js` — акт осмотра ООО «Фаворит» (Росгосстрах), лист 5 для КАСКО
- `lat_engine.js` — акт осмотра LAT / Т-Страхование
- `evak_engine.js` — акт осмотра при эвакуации (ФАВОРИТ)
- `holostoy_engine.js` — протокол осмотра территории (холостой выезд)
- `imush_pct.txt` — памятка РГС: ориентировочный % повреждения конструктивных элементов и инженерки
- `imush_engine.js` — акт осмотра имущества физлиц ООО «Фаворит» (Росгосстрах): титул, строение, общая схема, домашнее имущество, внутренняя отделка, квартира

Использование: `require("./favorit_engine.js")({ D, KOMPL, damages, ..., OUT_FILE })`
