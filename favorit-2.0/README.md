# Фаворит 2.0 — акт осмотра ТС РГС

**Основной рабочий генератор:** [`Favorit_AKT_autonomous.js`](Favorit_AKT_autonomous.js) из ветки `main`. Он содержит новый бланк от 18.11.2026, закодированное факсимиле и XML-разметку подписи внутри одного JS. Для сборки с его помощью **не нужны отдельные** `.docx`, `podpis.js`, `signature.png`, `drawing.txt`.

## Где находятся правила

- [`PROMPT.md`](PROMPT.md): обязательные правила осмотра, заполнения и проверки.
- [`knowledge/NEW_CHAT_START.md`](knowledge/NEW_CHAT_START.md): краткая инструкция для нового чата.
- [`knowledge/FAST_MODE.md`](knowledge/FAST_MODE.md): быстрый путь фото → список повреждений → PDF.
- [`tools/fast_build.py`](tools/fast_build.py): сборка и машинная проверка PDF.

## Как делать акт

1. Получить фото, документы, согласованный перечень; не додумывать реквизиты и дефекты.
2. Перед каждой сборкой читать актуальные `PROMPT.md` и `Favorit_AKT_autonomous.js` из GitHub `main`. При недоступности GitHub явно сообщить об ограничении, не подменять другой копией молча.
3. Сохранить рабочую копию автономного JS **в облачной песочнице ChatGPT**. Изменить только блок входных данных до `// Конец блока данных.`. Исходный код не трогать.
4. Запустить `tools/fast_build.py` по [правилам сборки](PROMPT.md) с согласованным перечнем повреждений и отчётом экспертной проверки. Сборщик вызывает Node.js, `zip` и `unzip` для DOCX, затем LibreOffice для PDF и проверяет результат до выдачи.
5. Проверить номер убытка на каждом листе, VIN, галочки, подписи, все строки повреждений и начало перечня строго с третьего листа. Выдать PDF. DOCX только по запросу.

**Важно:** пробник LADA XRAY на 22 позиции подтвердил генерацию и вёрстку, но создавался в тестовом режиме с неполными данными. Для реального акта действуют проверки обязательных реквизитов, стороны удара и ремонтных воздействий. `AKT_TEST=1` не использовать для выдачи окончательного страхового акта.

## Старые файлы

- `New_Favorit_AKT_refined.js`: сохранён как резервная предыдущая версия; использует отдельный DOCX и ресурсы.
- `favorit_engine.js` в корне репозитория: старый движок Клода, формирующий бланк через библиотеку `docx`. Не является генератором нового бланка.
- Старые движки других актов в корне репозитория оставлены без изменений.

GitHub хранит каноническую версию, но **не синхронизирует её автоматически с другими чатами ChatGPT**. Для проекта нужны согласованные инструкции проекта; для чатов за его пределами требуются пользовательские инструкции или явная ссылка на репозиторий. Файлы прошлой песочницы не следует считать доступными в новом чате.

Не хранить в публичном репозитории реальные СТС, фотографии клиентов и акты с персональными данными. Размещение используемого только для актов факсимиле определяет пользователь.
