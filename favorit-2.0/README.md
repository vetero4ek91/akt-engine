# Фаворит 2.0
Новая электронная форма акта осмотра ТС РГС. Старые движки в корне репозитория оставлены без изменений.

- `PROMPT.md`: действующие правила оформления и сборки.
- `New_Favorit_AKT_refined.js`: **ещё не загружен в эту папку**. Рабочая версия v4.2 пока только в файлах ChatGPT-проекта и архиве.
- `templates/`: оригинальный DOCX-бланк, используемый генератором (если добавляется).
- Факсимиле `signature.png` используется отдельно; для реальной сборки оно должно быть доступно в рабочей среде.

Производственный процесс: фотографии и направление → текстовый список повреждений → согласование → подстановка данных в JS → Node.js → DOCX → PDF → проверка → только PDF пользователю.

**GitHub хранит версии, но не синхронизирует файлы ChatGPT Project автоматически.** Перед запуском следует убедиться, что берётся актуальный рабочий JS и правила. Не хранить в репозитории реальные СТС, фотографии клиентов и акты с персональными данными.
